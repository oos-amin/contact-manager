# 📱 Contact Manager

**Contact Manager** is a lightweight, fast, and intuitive web application designed to manage your personal contacts efficiently. This project focuses on mastering **DOM Manipulation**, **Local Storage**, and creating **Responsive Designs** using pure web technologies. 

With this app, you can seamlessly add, edit, search, and delete contacts while ensuring your data stays safe even after a page refresh!

[🚀 View Live Demo](https://oos-amin.github.io/contact-manager/)

## ✨ Key Features

- ➕ **Add Contacts**: Quickly add new contacts with detailed information.
- 🔍 **Real-time Search**: Instant filtering of your contact list as you type.
- 📝 **Edit & Update**: Easily modify existing contact details.
- 🗑️ **Delete Functionality**: Remove contacts with a single click.
- 💾 **Data Persistence**: Powered by `localStorage` to keep your data saved in the browser.
- 📱 **Fully Responsive**: Optimized for a smooth experience on Mobile, Tablet, and Desktop.
